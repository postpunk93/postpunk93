# Александр Кузакин

Пишу лонгриды для Хабра и VC и собираю ИИ-инструменты, которыми пользуются
нетехнические коллеги. Интересен стык: текст, который выходит в топ, и
автоматизация, которая его производит.

Ищу роль на пересечении контента и ИИ — контент-инженер, вайбкодер, редактор
с автоматизацией.
